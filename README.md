# Mac Pro Homelab

A hands-on infrastructure project documenting the repair and conversion of a 2013 Mac Pro into a Proxmox-based homelab server.

The goal of this project is to build practical experience with virtualization, Linux administration, networking, storage, automation, and home infrastructure.

## Hardware

- Apple Mac Pro (Late 2013)
- Intel Xeon processor
- 32 GB DDR3 RAM
- 1 TB SSD
- Dual AMD FirePro D300 GPUs

More detailed hardware information can be found in [docs/hardware.md](docs/hardware.md).

## Planned Services

- Proxmox VE
- Linux virtual machines
- Home Assistant
- Docker containers
- Network storage
- Backup services
- Network monitoring
- Router and firewall experimentation

## Current Status

The Mac Pro is currently undergoing hardware repair.

The internal cooling fan is not functioning correctly, so sustained testing and virtualization workloads have been paused until the fan is replaced.

The issue and repair process are documented in:

[docs/troubleshooting.md](docs/troubleshooting.md)

## Project Goals

- Gain hands-on Proxmox experience
